Connection

TiinyBench finds the box on its own. A stock Tiiny answers on several addresses at once and which ones exist depends on how it is plugged in, so this tries them in order and keeps the first one that replies.

Address
Leave this alone unless detection missed. A direct address works too: the LAN IP, the USB address, or an IPv6 literal in brackets.
API key
One static key authorises everything on the device, so treat it like a root password. On the Mac running TiinyOS it is read out of the app automatically. Anywhere else, paste it here once.

Report

One self-contained HTML file built from every run. No CDN, no webfont, no JavaScript needed to read it. Works offline and you can email it.
